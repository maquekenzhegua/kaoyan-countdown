# 考研上岸挂历 · 28考研

一个为 2028 考研人打造的「挂历海报」风上岸倒计时应用(PWA):名校校园实拍 + 真实日历版式 + 大红倒计时数字,手机、电脑都能用。

## 功能

- 🏛️ 九所名校校园照片轮换:清北 + 华五 + C9(清华二校门、北大博雅塔、复旦光华楼、上交东门、浙大玉泉、南大北大楼、中科大水上报告厅、哈工大主路、西交主楼),点「换一所」或轻触照片切换
- 🎯 填写目标院校可锁定对应校园照片,每天自动轮换
- 🀄 挂历版式:红色月份带 + 农历 + 日历网格,今天标红圈,初试日标「考」
- ⏳ 大红倒计时数字 + 距开考精确到秒 + 「还能睡 N 个懒觉」
- 📈 备考进度条与「备考第 N 天」
- 💬 每日一句考研寄语,每天自动更换
- 📲 PWA:可「添加到主屏幕」,全屏运行,离线可用
- ⚙️ 初试日期、开考时间均可修改(28 考研准确日期以教育部公告为准,默认按惯例预估为 **2027 年 12 月 18 日 08:30**)

## 手机安装

### iPhone(Safari)
1. 用 Safari 打开本应用网址
2. 点底部「分享」按钮 → 「添加到主屏幕」
3. 桌面出现图标,点开即全屏运行,之后离线也能用

### 安卓(Chrome / Edge)
1. 用浏览器打开本应用网址
2. 菜单 → 「添加到主屏幕」/「安装应用」
3. 确认后桌面生成图标,点开即全屏运行

## 本地运行

任意静态服务器即可,例如:

```bash
python -m http.server 8788
# 打开 http://127.0.0.1:8788
```

## 文件说明

- `index.html` — 应用本体(样式、逻辑全部内置,无外部依赖)
- `manifest.webmanifest` — PWA 清单
- `sw.js` — Service Worker,离线缓存
- `solarlunar.min.js` — 农历转换库([solarlunar](https://github.com/chinese-lunar/solarlunar),MIT)
- `img/` — 九所高校校园照片(来源与授权见 [CREDITS.md](CREDITS.md))
- `icon-*.png` / `apple-touch-icon.png` — 应用图标
- `gen_icons.py` — 图标生成脚本(可选)
